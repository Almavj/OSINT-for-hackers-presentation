# OSINT

This project is a practical collection of OSINT training material focused on understanding how public information is gathered, analyzed, and used in security work.

It is designed to help security practitioners and defenders learn how to map exposed assets, validate findings, and think like investigators without crossing into unauthorized or malicious activity.

## What this project covers

- Reconnaissance and intelligence gathering from public sources
- Domain, infrastructure, and subdomain discovery
- Search-engine and metadata-based discovery techniques
- Human and identity-related research patterns
- Responsible investigation tradecraft and reporting

## Purpose

The goal is to teach structured, ethical OSINT: collecting information that is already public, validating it carefully, and turning it into useful security insight.

This is not a tool dump or a malicious playbook. It is a reference for understanding exposure, threat surface, and defensive awareness.

## Intended audience

- Security engineers
- Red teamers and penetration testers
- SOC and analyst teams
- Blue-team defenders
- Anyone learning offensive and defensive reconnaissance responsibly

## Important note

All methods should be used only with proper authorization and in a lawful, ethical context.
